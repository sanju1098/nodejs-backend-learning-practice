# Docker Fundamentals for Node.js

Docker is one of the most important tools used in modern backend development. It helps developers package applications and their dependencies into portable containers that run consistently across different environments.

---

# Real-World Problem

Imagine two developers working on the same project:

### Developer 1

- Node.js 22
- MongoDB 8
- Windows

### Developer 2

- Node.js 18
- MongoDB 6
- macOS

The application may behave differently because of version differences and operating system configurations.

### Docker Solution

Docker solves this.

```text
Application + Dependencies + Runtime + Configuration = Container
```

Runs the same everywhere.

---

# What is Docker?

Docker is a containerization platform that allows developers to package applications with all required dependencies.

Without Docker:

```text
Install Node.js
Install MongoDB
Install Packages and Dependencies
Configure Environment Variables
```

With Docker:
Create a Dockerfile that defines the environment and dependencies.
Build an image from the Dockerfile.

docker run app
Everything is already inside.

# Common Docker Commands

## Build Image

Build a Docker image from the Dockerfile.

```bash
docker build -t <image-name> .
```

Example:

```bash
docker build -t day21-img .
```

---

## View Images

Display all available Docker images.

```bash
docker images
```

---

## Run Container

Create and start a container from an image.

```bash
docker run -p 5000:5000 <image-name>
```

Example:

```bash
docker run -p 5000:5000 day21-img
```

---

## View Running Containers

Display all currently running containers.

```bash
docker ps
```

Shows:

- Container ID
- Image Name
- Status
- Port Mapping

---

## Stop Container

Stop a running container.

```bash
docker stop <container-id>
```

Example:

```bash
docker stop abc123
```

---

## Run Container in Background

Start a container in detached mode.

```bash
docker run -d -p 5000:5000 <image-name>
```

Example:

```bash
docker run -d -p 5000:5000 day21-img
```

---

## View All Containers

Display both running and stopped containers.

```bash
docker ps -a
```

---

## View Container Logs

View logs generated by a container.

```bash
docker logs <container-id>
```

Example:

```bash
docker logs abc123
```

---

## Remove Container

Delete a stopped container.

```bash
docker rm <container-id>
```

Example:

```bash
docker rm abc123
```

---

## Remove Image

Delete a Docker image using its image ID.

```bash
docker rmi <image-id>
```

Example:

```bash
docker rmi xyz456
```

---

## Remove Image by Name

Delete a Docker image using its name.

```bash
docker rmi <image-name>
```

Example:

```bash
docker rmi day21-img
```

# Interview Questions & Answers

## What is Docker?

**Answer:**

Docker is a containerization platform that packages applications and their dependencies into portable containers that run consistently across different environments.

---

## What is a Container?

**Answer:**

A container is a running instance of a Docker image.

It contains:

- Application Code
- Runtime
- Dependencies
- Configuration

---

## What is an Image?

**Answer:**

A Docker image is a blueprint used to create containers.

It contains everything required to run an application.

---

## Difference Between Image and Container?

| Image                     | Container           |
| ------------------------- | ------------------- |
| Blueprint                 | Running Instance    |
| Read-only                 | Executable          |
| Static                    | Dynamic             |
| Used to Create Containers | Created from Images |

---

## What is a Dockerfile?

**Answer:**

A Dockerfile is a configuration file that contains instructions for building a Docker image.

---

## What is the Purpose of EXPOSE?

**Answer:**

`EXPOSE` documents the port used by the application inside the container.

Example:

```dockerfile
EXPOSE 5000
```

---

## What is the Purpose of CMD?

**Answer:**

`CMD` specifies the default command that runs when the container starts.

Example:

```dockerfile
CMD ["npm", "start"]
```

---

## What Does docker build Do?

**Answer:**

Creates a Docker image from the instructions defined in the Dockerfile.

Example:

```bash
docker build -t notes-api .
```

---

## What Does docker run Do?

**Answer:**

Creates and starts a container from a Docker image.

Example:

```bash
docker run -p 5000:5000 notes-api
```

---

## Why Use .dockerignore?

**Answer:**

`.dockerignore` prevents unnecessary files from being copied into Docker images.

Benefits:

- Smaller image size
- Faster build times
- Improved security
